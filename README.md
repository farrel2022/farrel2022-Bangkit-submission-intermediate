# Submission Intermediate – Bangkit Academy

> Proyek tugas akhir Intermediate untuk program Bangkit Academy

---

## 🎯 Tentang Proyek
Repositori ini berisi proyek “Submission Intermediate” yang dikembangkan dalam rangka kurikulum Bangkit Academy.  
Proyek ini ditujukan sebagai lanjutan dari tugas Android pemula, dengan kompleksitas fitur dan arsitektur yang lebih matang.

---

## 🛠 Teknologi & Alat yang Digunakan
- Bahasa : Kotlin  
- Platform : Android (SDK >= XX)  
- Arsitektur : MVVM / Clean Architecture (sesuai desain)  
- API/Networking : Retrofit + OkHttp  
- Database/Local : Room atau lainnya (jika ada)  
- Build : Gradle dengan Kotlin DSL  
- Alat pengembangan : Android Studio

---

## 🧩 Fitur Utama
- Autentikasi pengguna / login (jika ada)  
- Mengambil data dari API dan menampilkan daftar  
- Menampilkan detail item/data  
- Fitur interaksi pengguna (ikuti, favorit, dll)  
- Penyimpanan data lokal untuk akses offline  
- UI responsif dan desain modern (Material Design)  
- Pengujian unit & instrumentasi (opsional)

---
